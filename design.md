## Creative North Star

**Atmospheric Minimalism** — the interface is a curated exhibition space. We prioritize the "void" as much as the content, using dark, cinematic depth to make artwork feel illuminated from within. Intentional asymmetry, generous whitespace, and high-contrast typography scales create an editorial experience that feels quiet, authoritative, and expensive.

## Core Rules

### The "No-Line" Rule
Never use 1px solid borders to section content. Boundaries come from background color shifts only. A `surface-container-low` section against `surface` creates a seamless "liquid" flow.

### The "Glass & Gold" Rule
- Floating nav: `surface-variant` at 60% opacity + 24px backdrop blur
- Primary CTAs: Linear gradient from `primary` (#e6c364) to `primary-container` (#c9a84c) at 135deg — metallic sheen, not flat fill

### Zero Roundedness
All elements use 0px border-radius. Sharp corners = architectural precision.

### No Pure White
Never use #FFFFFF. Use `on-surface` (#e5e2e1) — aged paper/limestone tone.

### Tonal Layering (No Box Shadows)
Depth through stacked background tones, not drop shadows. If shadow is required, 40px blur at 6% opacity, tinted with surface-container-lowest.

## Components

### Buttons
- **Primary:** Gold gradient fill, sharp corners, dark text (#3d2e00)
- **Secondary:** Ghost style — transparent with outline-variant border, gold text
- **Tertiary:** Text-only, uppercase label-md, 0.1rem letter spacing

### Art Cards
- Image-centric, sharp corners
- `surface-container-lowest` for image placeholder wells
- No divider lines — 24-32px vertical spacing between items
- Hover: background shift to `surface-container-highest`

### Curator's Overlay (Lightbox)
Full-screen `surface` at 80% opacity + high backdrop-blur. Only art title (display-md) and specs (label-sm) visible. Everything else stripped away.
